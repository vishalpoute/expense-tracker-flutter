# Expense Tracker

A Flutter expense-tracking project with BLoC state management, a Firestore repository and an equal-share expense splitter.

## Features

- Expense and category workflows
- Firebase-backed repository package
- Expense splitting and chart UI

## Stack

Flutter · Dart · BLoC · Firebase · Firestore

## Run locally

```sh
flutter pub get
flutter run --dart-define-from-file=firebase.local.json
```

See [SECURITY.md](SECURITY.md) for local Firebase configuration and API-key handling.

## Project status

Chart values include sample data. This repository includes contributions from multiple developers; commit history records attribution.
